# 验收记录

构建和验证都是在自己的电脑上做的（Windows + Docker Desktop）。

## 构建

命令：

```bash
docker build --build-arg HERMES_VERSION=0.20.5 -t hermes:0.20.5 .
```

构建成功，完整日志截图在 `pictures/02-完整构建日志.png`。关键几步的输出：

```
#10 Requested: 0.20.5
#10 Source:    0.20.5
#12 + hermes-agent==0.20.5 (from file:///opt/hermes-agent)
#13 Hermes Agent v0.20.5 (2026.8.19)
#14 naming to docker.io/library/hermes:0.20.5 done
```

版本校验那一步 Requested 和 Source 都是 0.20.5，一致，没有报错。

## 验证

```bash
docker images hermes:0.20.5
```

```
hermes:0.20.5   ea911a5f01b6   1.27GB   349MB
```

```bash
docker run --rm hermes:0.20.5 hermes --version
```

```
Hermes Agent v0.20.5 (2026.8.19)
Install directory: /opt/hermes-agent
Python: 3.11.2
OpenAI SDK: 2.24.0
```

容器里的版本号和传入的 0.20.5 一致。截图在 `pictures/01-镜像列表与版本验证.png`。

另外进容器确认过 hermes 命令能直接用，镜像里也没有 TencentDB 记忆插件。
